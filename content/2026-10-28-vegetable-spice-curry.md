「肉がない日でも、スパイスカレーを作れたらいいのに」と思ったことはありませんか。
野菜だけで作るスパイスカレーは、肉のカレーより軽やかで、野菜の甘みがそのまま味になる一皿です。肉を使わなくても満足する味にする鍵は3つ。玉ねぎをしっかり炒めてうまみの土台を作る、トマトで酸味とうまみを足す、じゃがいもとなすでとろみとこくを出す。この3つがそろうと、「何か足りない」と感じなくなります。
この記事では、2〜3人分の材料表と番号つきの手順、季節の野菜への替え方、豆やココナッツミルクで広げる食べ方を紹介します。

## 野菜だけのカレーが「物足りなく」ならないために

野菜カレーが物足りなく感じる原因は、味が薄いことよりも、うまみとこくの層が少ないことです。肉のカレーでは、肉の脂とうまみが自然にこの層を作ってくれます。野菜だけで作るときは、その役目を次の食材に分けて持たせます。

| 役目 | 野菜カレーで担当する食材 | 働き |
|---|---|---|
| うまみの土台 | 玉ねぎ（しっかり炒める） | 甘みと香ばしさ。ここが浅いと全体がぼやける |
| 酸味とうまみ | トマト | 味を引き締め、スパイスをまとめる |
| とろみ | じゃがいも | 煮くずれた部分が自然なとろみになる |
| こくと油のなじみ | なす | 油を吸って、口当たりに厚みが出る |
| 香り | クミンシード・にんにく・しょうが | 最初の油に香りを移す |
| 仕上げの厚み | バターまたはヨーグルト（好みで） | 乳のこくが足りない部分を補う |

このうち、玉ねぎの炒め方がいちばん味を左右します。縁が茶色くなるまで炒めると、甘みと香ばしさが出て、肉がなくても「ちゃんとしたカレー」の味になります。炒め加減の見分け方は、[玉ねぎの炒め方で変わるスパイスカレーの味](sauteing-onions.html)でくわしく紹介しています。

はじめて作る人からは、こんな声も聞きます。「野菜カレーって、結局いつもの野菜炒めみたいな味になりませんか」。それは、玉ねぎとトマトの工程を急いだときに起きやすい現象です。この2つだけ時間をかければ、味の印象ははっきり変わります。

## 材料（2〜3人分）

| 材料 | 分量 |
|---|---|
| 玉ねぎ | 1個（大きめ） |
| トマト | 1個（またはカットトマト缶 150g） |
| じゃがいも | 2個（約250g） |
| なす | 2本 |
| にんじん | 1/2本 |
| ピーマンまたはパプリカ | 1個 |
| にんにく（みじん切り） | 1かけ |
| しょうが（みじん切り） | 1かけ |
| サラダ油 | 大さじ3 |
| クミンシード | 小さじ1 |
| ターメリック | 小さじ1/2 |
| コリアンダーパウダー | 小さじ2 |
| クミンパウダー | 小さじ1 |
| チリパウダー（お好みで） | 小さじ1/4〜 |
| ガラムマサラ（あれば） | 小さじ1/2 |
| 塩 | 小さじ1（味を見て調整） |
| 水 | 300ml |
| バターまたはプレーンヨーグルト（仕上げ用、お好みで） | 10g または大さじ2 |

油は、肉のカレーより少し多めです。なすが油を吸うので、ここを減らすとこくが出にくくなります。スパイスは、[基本のチキンカレーの作り方](basic-chicken-curry.html)で使う3種（ターメリック・コリアンダー・クミン）があれば作れます。

## 作り方

1. 玉ねぎはみじん切り、トマトはざく切りにします。じゃがいもは皮をむいて一口大、にんじんは小さめの乱切り、なすは一口大の乱切りにして水に5分さらし、水気を切ります。ピーマンは一口大に切ります。
2. 鍋にサラダ油とクミンシードを入れて弱めの中火にかけ、シードのまわりに細かい泡が出て香りが立つまで加熱します。焦げると苦くなるので、泡が出たらすぐ次へ進みます。
3. 玉ねぎを加え、中火で10〜12分、縁が茶色くなるまで炒めます。途中で焦げつきそうなら、水を大さじ1ずつ足して鍋底をこそげます。
4. にんにくとしょうがを加え、香りが出るまで1分ほど炒めます。
5. トマトを加え、木べらでつぶしながら、水分が飛んでペースト状になるまで4〜5分炒めます。油がにじんで見えてきたら、次に進む合図です。
6. 火を弱め、ターメリック、コリアンダーパウダー、クミンパウダー、チリパウダー、塩を加えて、全体にからめながら30秒ほど炒めます。
7. じゃがいもとにんじんを加えて中火にし、スパイスのペーストをからめながら2分炒めます。
8. 水を加えてふたをし、沸いたら弱火で10分煮ます。
9. なすを加え、ふたをして弱火でさらに8〜10分、じゃがいもに竹串がすっと通るまで煮ます。じゃがいもの角が少しくずれてきたら、それが自然なとろみになります。
10. ピーマンを加えて2〜3分煮ます。ガラムマサラを加えて混ぜ、味を見て塩で調えます。好みでバターかヨーグルトを加えて、全体がなじんだら火を止めます。

野菜は中心まで火を通し、作ったその日に食べ切るか、残りは粗熱が取れたらすぐに冷蔵庫へ入れてください。室温に長く置かないのが、どんなカレーにも共通する基本です。

## 季節の野菜への替え方

この作り方は、「土台の野菜（玉ねぎ・トマト）」と「主役の野菜（じゃがいも・なすなど）」が分かれているので、主役の野菜は季節で替えられます。

| 季節 | 替えやすい野菜 | 入れるタイミングの目安 |
|---|---|---|
| 春 | 新じゃが、スナップえんどう、アスパラ | 新じゃがは皮ごと。えんどうとアスパラは最後の3分 |
| 夏 | ズッキーニ、オクラ、とうもろこし | ズッキーニはなすと同じ。オクラは最後の3分 |
| 秋 | かぼちゃ、さつまいも、きのこ | かぼちゃ・さつまいもはじゃがいもと同じ。きのこは最後の5分 |
| 冬 | 大根、かぶ、ほうれん草 | 大根・かぶはじゃがいもと同じ。ほうれん草は最後の2分 |

替えるときの目安は、「じゃがいものような固い野菜は早く、葉もの・さやものは最後に」です。固い野菜を1種類は残しておくと、とろみが出て、食べごたえも保てます。かぼちゃやさつまいもを使う日は、甘みが強くなるので、チリパウダーを少し増やすか、仕上げにレモンを数滴たらすと、味が締まります。

## 豆やココナッツミルクで広げる

同じ作り方のまま、2つの食材を足すと、別のカレーのように楽しめます。

- **ゆで大豆やひよこ豆（水煮）を1缶**：手順8で水と一緒に加えます。豆のたんぱく質と食感で、肉なしでもぐっと満足感が増します。豆が主役のカレーは[ダルカレー（豆カレー）の作り方](dal-curry.html)でも紹介しています
- **ココナッツミルクを100〜200ml**：手順8の水の一部をココナッツミルクに替えます。まろやかになり、なすやかぼちゃとの相性がよくなります。ココナッツミルクは煮立てすぎると分離しやすいので、加えたら弱火で
- **トマトを増やす**：トマト缶を1缶（400g）に増やし、水を200mlに減らすと、酸味の立った軽やかな味になります

野菜カレーは、肉のカレーより味の輪郭がやさしい分、副菜の塩気や酸味がよく合います。ヨーグルトのライタや、玉ねぎのアチャールなど、[スパイスカレーのおすすめの副菜](spice-curry-side-dishes.html)を一品添えると、食卓の満足度が上がります。

## 作り置きと注意点

野菜カレーは、翌日のほうが味がなじんで、おいしく感じる人も多い料理です。保存のしかたは、ひとつだけ気をつけます。

- 粗熱が取れたら、浅い容器に移して**すぐ冷蔵庫**へ。鍋のまま室温に置かない
- 冷蔵で2日を目安に、食べるときは中心までしっかり再加熱する
- 冷凍するなら、じゃがいもは食感が変わりやすいので、つぶしてから冷凍するか、取り除いて冷凍する

作り置き全体のコツと、安全に保存する考え方は、[スパイスカレーの作り置きと冷凍のコツ](make-ahead-freezing.html)にまとめています。

向かない場面もひとつ。野菜だけのカレーは、肉のカレーに比べて、腹持ちの面で物足りなく感じる人もいます。そんなときは、豆を加える、ゆで卵を添える、ごはんにターメリックライスを選ぶなど、一品足す形で調整するほうが、カレーそのものを重くするより、野菜の味を生かせます。

## まとめ

- 野菜だけで満足する味にする鍵は、**玉ねぎをしっかり炒める・トマトで酸味とうまみを足す・じゃがいもとなすでとろみとこくを出す**の3つ
- 油は肉のカレーより少し多め。なすが油を吸って、こくになります
- 主役の野菜は季節で替えられる。**固い野菜は早く、葉もの・さやものは最後に**。固い野菜を1種類は残すととろみが出る
- 豆1缶やココナッツミルクで、同じ作り方のまま別のカレーに広がる
- 保存は粗熱が取れたらすぐ冷蔵庫へ。2日を目安に、しっかり再加熱
