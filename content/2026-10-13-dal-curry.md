ダルカレーは、豆を煮込んで作るカレーです。「ダル」は、インドなどで食べられている挽き割りの豆や、それを使った料理を指す言葉です。
この記事では、浸水しなくても短時間で煮える皮むきのレンズ豆を使った、はじめてでも作りやすいダルカレーを紹介します。

## ダルカレーに使う豆の種類

ダルカレーにはさまざまな豆が使われますが、日本で手に入りやすく、はじめての人に使いやすいのは次の豆です。

| 豆 | 特徴 | 浸水 |
|---|---|---|
| 皮むきレンズ豆（マスールダール） | オレンジ色。煮るとすぐに崩れてなめらかになる | 不要 |
| ムングダール（皮むき緑豆） | 黄色。やさしい味で、比較的早く煮える | 不要なことが多い |
| ひよこ豆（乾燥） | 粒が残り、ほくほくした食感 | 必要（ひと晩程度） |

このレシピでは、**皮むきのレンズ豆**を使います。浸水が不要で、20分ほど煮れば形が崩れてとろりとするので、思い立ったときにすぐ作れます。豆によって煮える時間は違うので、ほかの豆を使う場合は袋の表示を確認してください。

## 材料（2〜3人分）

| 材料 | 分量 |
|---|---|
| 皮むきレンズ豆（乾燥） | 150g |
| 水 | 600ml（煮詰まり具合で追加） |
| ターメリック | 小さじ1/2 |
| 塩 | 小さじ1（味を見て調整） |
| 玉ねぎ | 中1/2個 |
| トマト | 中1/2個 |
| にんにく | 1かけ |
| しょうが | 1かけ（にんにくと同量程度） |
| サラダ油（またはギー） | 大さじ2 |
| クミンシード | 小さじ1 |
| 赤唐辛子（お好みで） | 1本 |
| コリアンダーパウダー | 小さじ1 |

### 下ごしらえ

- レンズ豆はざるに入れ、水が透明に近くなるまで数回すすぎます。
- 玉ねぎは薄切り、トマトは粗く刻みます。
- にんにくは薄切り、しょうがはみじん切りにします。
- 赤唐辛子は種を除きます（辛くしたい場合は種ごと使います）。

## 作り方

手順1〜2で豆を煮て、手順3〜6で香りの油を作って合わせる、という2段階で作ります。

1. **豆を煮立てる（強めの中火・約5分）**：鍋にレンズ豆、水600ml、ターメリックを入れて火にかけます。沸騰すると白い泡が出てくるので、お玉ですくい取ります。
2. **やわらかく煮る（弱火・ふたを少しずらして約15〜20分）**：火を弱め、ときどき鍋底から混ぜながら煮ます。豆が崩れてとろりとしたら火を止め、塩を加えて混ぜます。水分が足りなくなったら、水を少しずつ足してください。
3. **スパイスを加熱する（弱めの中火・約1分）**：別のフライパンにサラダ油、クミンシード、赤唐辛子を入れて火にかけます。泡が出て香りが立つまで加熱します。
4. **香味野菜を炒める（中火・約5〜7分）**：にんにく、しょうが、玉ねぎを加え、玉ねぎがきつね色になるまで炒めます。
5. **トマトとパウダーを加える（弱火・約2〜3分）**：トマトを加えて少し崩れるまで炒め、火を弱めてコリアンダーパウダーを加え、全体になじませます。
6. **豆と合わせる（弱めの中火・約3〜5分）**：フライパンの中身を豆の鍋に加えてよく混ぜ、軽く煮て全体をなじませます。味見をして、塩で調えたら完成です。

このように、加熱したスパイスと香味野菜の油を最後に加える工程を「テンパリング」や「タルカ」と呼ぶことがあります。豆の素朴な味に、香ばしい香りが加わります。

## おいしく作るためのポイント

### 鍋底の焦げ付きに注意する

豆が崩れてとろみが出てくると、鍋底に沈んで焦げ付きやすくなります。後半はとくに、ときどき鍋底からしっかり混ぜてください。

### とろみは水で調整する

ダルカレーは、冷めるとさらにとろみが強くなります。仕上がりがかたいと感じたら水を足し、ゆるいと感じたら少し煮詰めて調整してください。スープのようにさらっと仕上げるのも、ぽってり仕上げるのも好みです。

### 具材を足してアレンジする

ダルカレーは、野菜を加えてもおいしく作れます。ほうれん草を加える場合は、ざく切りにして仕上げの段階で入れ、しんなりするまで煮ます。かぼちゃやにんじんなどの根菜は、豆と一緒に最初から煮ると、豆が煮えるころにやわらかくなります。具材を加えると水分や塩加減が変わるので、最後にもう一度味見をしてください。

### 豆の状態を確認する

乾燥豆には、まれに小石や殻などが混じっていることがあります。すすぐ前に平らな皿やバットに広げ、ざっと目で確認しておくと安心です。見つけたものは取り除いてからすすいでください。

### 塩を入れてから味を見る

豆のカレーは、塩が足りないと味がぼやけやすい料理です。最後に必ず味見をして、少しずつ塩を加えて調整してください。

### 香りを変えてみる

香りの油に使うスパイスを変えると、印象が変わります。クミンシードの代わりにマスタードシードを使ったり、仕上げにガラムマサラを少量加えたりするのもおすすめです。ホールとパウダーの使い分けは「[ホールスパイスとパウダーの使い分け｜入れるタイミングと香りの違い](whole-vs-ground-spices.html)」を参考にしてください。

## 保存と温め直し

ダルカレーは作り置きもできますが、次の点に注意してください。

- 浅い保存容器に小分けして早めに冷まし、粗熱が取れたら冷蔵庫に入れます
- 冷えるとかたくなるので、温め直すときは水を少し足します
- 鍋の場合は混ぜながら、全体がしっかり沸騰するまで加熱します

## まとめ

ダルカレーは、手に入りやすいレンズ豆で作れる、やさしい味のカレーです。

- 皮むきのレンズ豆なら浸水不要で、約20分で煮える
- 豆を煮るときに出る泡はすくい取る
- 最後に香りの油（テンパリング）を加えて、香りを決める
- とろみは水と煮詰め具合で調整する
- 鍋底が焦げやすいので、ときどき底から混ぜる

肉のカレーと組み合わせて、2種類のカレーを盛り合わせるのも楽しい食べ方です。肉のカレーは「[基本のチキンカレーの作り方｜3つのスパイスで作るはじめてのスパイスカレー](basic-chicken-curry.html)」を参考にしてください。
