ターメリックはどんなスパイス？

ターメリックは、ショウガ科の植物の根茎（地下で育つ茎の部分）を乾燥させ、粉にしたスパイスです。家庭のスパイスカレーでは、ほとんどの場合パウダーを使います。

スパイスカレーでの主な役目は、次の2つです。

  • 色：鮮やかな黄色をつける
  • 香り：土を思わせる、少しほろ苦い落ち着いた香りを加える

辛さはほとんどありません。そのため、辛いものが苦手な方や、お子さんと一緒に食べるカレーにも使いやすいスパイスです。

なお、このサイトでは料理の味と作り方を扱っており、ターメリックの健康面の話題には触れません。

量の目安は「少なめ」から

ターメリックは、少しの量でも色がよく出ます。このサイトの基本のレシピでは、2〜3人分で次の量を使っています。

カレーの種類ターメリックの目安（2〜3人分）
チキンカレー・キーマカレー小さじ1/2
ダルカレー（豆カレー）小さじ1/4〜1/2
ターメリックライス（米2合）小さじ1/4〜1/2

ほかのパウダースパイスより量が少ないのは、多く入れると苦みや粉っぽさが出やすいからです。色が薄いと感じても、まずは目安の量で仕上げてみると、香りのバランスがとりやすくなります。

入れるタイミングと炒め方

基本は「トマトの後・弱火で」

ターメリックは、クミンやコリアンダーのパウダーと一緒に、トマトを炒めた後に加えるのが基本です。

  1. 玉ねぎをきつね色まで炒め、にんにく・しょうがを加えます。
  2. トマトを加え、つぶしながら水分を少し飛ばします。
  3. 火を弱めて、ターメリックとほかのパウダースパイス、塩を加えます。
  4. 粉っぽさがなくなるまで、1〜2分炒めます。

パウダーは焦げやすいので、火を弱めてから入れると安心です。トマトの水分があると、スパイスがなじみやすく、焦げにくくなります。

油で軽く炒めると色が冴える

ターメリックの色の成分は、水より油になじみやすいといわれています。具材に油がまわった状態で炒めると、色がムラなく広がりやすくなります。

玉ねぎの炒め具合も、カレーの色に影響します。玉ねぎの色と時間の目安は「玉ねぎの炒め方で変わるスパイスカレーの味｜段階別の色と時間の目安」で紹介しています。

カレー以外にも少しずつ

ターメリックは、カレー以外の料理にも使えます。どれも、ほんのひとつまみから試せます。

  • 野菜炒め：キャベツやじゃがいもを炒めるとき、塩と一緒にひとつまみ加えると、やさしい黄色になります
  • スープ：コンソメや鶏がらのスープに少し溶かすと、見た目が明るくなります
  • 卵料理：炒り卵やオムレツの卵液に少量混ぜると、色が鮮やかになります

少量でも色がよく出るので、まずは耳かき数杯ほどから始めて、好みの色を探してみてください。

入れすぎたときの立て直し方

量を多く入れてしまっても、次の方法で味をやわらげられます。

  • 具材や水を足す：全体の量を増やして、ターメリックの割合を下げます
  • トマトやヨーグルトを加える：酸味やコクが、苦みを感じにくくします
  • 塩を見直す：塩が足りないと苦みが目立つことがあるので、味見をしながら少しずつ加えます
  • ほかのスパイスで香りを重ねる：仕上げにクミンやガラムマサラを少し加えると、香りの印象が変わります

いちばん簡単な対策は、入れる前に計量スプーンで量を測ることです。小さじ1/2のスプーンが1本あると、毎回同じ色に仕上げやすくなります。

色移りを防ぐコツ

ターメリックの黄色は、道具や布に移りやすいのが特徴です。次の点を知っておくと、後片付けが楽になります。

  • まな板・保存容器：プラスチック製は色が残りやすいので、ガラスやホーローの容器を使うと安心です
  • 木べら：使い続けると黄色く染まりますが、料理に使う分には気にしなくて大丈夫です
  • 服・ふきん：ついたらすぐに水で洗い流し、早めに洗濯すると落ちやすくなります
  • コンロまわり：飛び散ったら、乾く前に台所用洗剤でふき取ります

カレーを作る日は、色が目立ちにくいエプロンを使うのもひとつの方法です。

ターメリックライスの作り方

カレーの色をもう一品で楽しみたいときは、ターメリックライスがおすすめです。炊飯器で手軽に作れます。

材料（2〜3人分）分量
米2合
ターメリック小さじ1/4〜1/2
塩ひとつまみ
バター（またはサラダ油）小さじ1〜2
  1. 米を洗い、炊飯器の2合の目盛りまで水を入れます。
  2. ターメリックと塩を加え、底からよく混ぜて溶かします。
  3. バターをのせて、普通に炊きます。
  4. 炊き上がったら、底から全体をさっくり混ぜます。

炊いたごはんは、室温に長く置かず、残った分は早めに冷蔵・冷凍すると安心です。

まとめ

ターメリックは、少しの量でカレーをきれいな黄色にしてくれるスパイスです。

  • 2〜3人分なら小さじ1/2を目安にする
  • トマトを炒めた後、弱火でほかのパウダーと一緒に加える
  • 入れすぎたら、具材・水・トマト・塩で調整する
  • 色移りしやすいので、容器はガラスやホーローが安心
  • ターメリックライスにすると、色をもう一品で楽しめる
